# <p align="center"> Statistics in C </p>

### 1.0 Why

Statistics can be carried over to absolutely anything, Also, because I can.

### 2.0 Notes
- I use [Nix](https://github.com/NixOS/nix) for almost all my projects. I also only install libraries (eg. Raylib, GSL, etc.) only when i need them. Therefore, I do my projects inside a *nix-shell*.
- Packages/libraries are declared inside *shell.nix* file.

### 3.0 Usage
1. Declare packages/libraries inside [shell.nix](shell.nix).
2. Enter nix-shell using,
```bash
nix-shell
```
3. Exit shell when done,
```bash
exit
```
